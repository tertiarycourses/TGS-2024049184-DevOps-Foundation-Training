## About the course

This WSQ course connects DevOps culture, flow, automation, measurement, reliability and security
to a structured problem-management lifecycle. Learners work with reproducible R analyses to turn
incident, telemetry, pipeline and delivery data into evidence-based recommendations.

## Learning outcomes

- Manage the lifecycle of problems using DevOps principles and technologies.
- Perform investigations and develop DevOps methods for problem analysis.
- Recommend DevOps solutions and monitor documentation for problem solving.

## Topics covered

- Exploring DevOps and its business value.
- Core DevOps principles, including flow, feedback and continual learning.
- Key practices across continuous integration, delivery, reliability and problem management.
- Business and technology frameworks that support DevOps adoption.
- Culture, behaviours, collaboration and operating models.
- Automation and DevOps toolchains.
- Measurement, DORA metrics, reporting and evidence-based improvement.
- Sharing, shadowing and evolving DevOps capabilities.
