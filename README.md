# DevOps Foundation Training

WSQ courseware for **TGS-2024049184**, produced by Tertiary Infotech Academy Pte Ltd.

Version: **v4.0** · 20 August 2026
Duration: **2 days / 16 hours** — 14 hours facilitated learning plus 2 hours assessment

## Learning outcomes

- Manage the lifecycle of problems using DevOps principles and technologies.
- Perform investigations and develop DevOps methods for problem analysis.
- Recommend DevOps solutions and monitor documentation for problem solving.

## Package

- `courseware/DevOps Foundation Training-v4.0.pptx` — highly visual, concept-led trainer deck with editable native PowerPoint charts.
- `courseware/DevOps Foundation Training-v4.0.pdf` — learner slide copy.
- `courseware/LG-DevOps Foundation Training.docx|pdf` and `LG-DevOps Foundation Training.md` — detailed Learner Guide and searchable mirror.
- `courseware/LP-DevOps Foundation Training.docx|pdf` — two-day Lesson Plan mapped to the final deck.
- `labs/` — eight connected, self-contained R labs with synthetic data, detailed instructions, checklists and reproducible outputs.

## Distribution boundary

Assessment instruments, answer keys, source references, credentials and build tooling are intentionally excluded from this public repository. Candidate assessment papers are distributed through LMS-TMS; answer keys remain trainer-only on Google Drive.
